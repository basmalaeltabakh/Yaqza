🧠 Model Architectures
From a linear baseline to deep sequential networks
Phase 1: Ridge Regression (Baseline) Very Low Cost
▼
Objective: Verify that PCA components have a real linear relationship with RUL, and establish a benchmark for more complex models.
Hyperparameter: alpha = 1.0  |  Cost: Very Low
Conclusion: Trains almost instantly. Any model after this must meaningfully reduce RMSE to justify its extra computational cost.
Phase 2: Random Forest & XGBoost Medium Cost
▼
Objective: Use non-linear ensemble methods to capture complex interactions between sensors.
Random Forest: Captures non-linear degradation patterns using an ensemble of decision trees, reducing variance and improving robustness against outliers.
XGBoost: Sequentially reduces prediction error, focusing more on cases where the machine is close to failure (the most critical point to predict).
Phase 3: LSTM Network High Cost
▼
Objective: Capture long-term temporal dependencies and sequential degradation patterns directly from raw sensor streams. Suitable for Edge Inference and Industrial IoT integration.
Architecture Highlights:
  • Bypasses manual feature extraction via PCA
  • Multiple LSTM (Long Short-Term Memory) layers
  • Connected Dense layers for the regression output
  • Optimized using the Adam optimizer
